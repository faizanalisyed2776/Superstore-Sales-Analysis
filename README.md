# Superstore Sales Data Exploration & Analysis Strategy

## 📌 Project Overview
This project provides a foundational Exploratory Data Analysis (EDA) and strategic roadmap for analyzing retail transactional data using Python. The objective is to evaluate key revenue drivers, assess profitability anomalies across regional hubs, and formulate data-driven hypotheses regarding discount structures.

## 📁 Repository Structure
- `generate_doc.py` - Python script that generates the complete assignment Word document.
- `Data_Analytics_Assignment.docx` - Detailed Week 1 exploration report, problem statement, and strategic plan.
- `superstore_sales.csv` - Target transactional dataset.

## 🛠️ Tools & Libraries Used
- **Language:** Python
- **Libraries:** Pandas, NumPy, Seaborn, Matplotlib, python-docx

## 💡 Key Highlights & Problem Statement
Despite achieving high top-line revenue, certain product sub-categories show negative net profit margins due to aggressive regional discounting strategies (>20%). This analysis lays the groundwork for predictive modeling and margin optimization.
